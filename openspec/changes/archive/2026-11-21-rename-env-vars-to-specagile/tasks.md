# Tasks

Cada grupo cambia una variable en `src/` junto con el entorno de la suite y los tests que dependen de ella, así la suite no queda a medio cambiar entre grupos. Para listar los archivos de un nombre: `git grep -l <NOMBRE> -- src test vitest.config.ts vitest.setup.ts scripts .github`. En Windows, `pnpm test -- --run <rutas>` no filtra: usar `pnpm exec vitest run <rutas>`.
