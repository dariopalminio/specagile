# Tasks

Cada grupo cambia una variable en `src/` junto con el entorno de la suite y los tests que dependen de ella, así la suite no queda a medio cambiar entre grupos. Para listar los archivos de un nombre: `git grep -l <NOMBRE> -- src test vitest.config.ts`. En Windows, `pnpm test -- --run <rutas>` no filtra: usar `pnpm exec vitest run <rutas>`.

## Workflow follow-up

- Commits separados: uno con `openspec/changes/rename-env-vars-to-specagile/` y otro con el código, los tests y la documentación.
- `flake.nix` cambia, así que el pull request ejecuta la validación de Nix en CI. Revisar que pase.
- Archivar el change con la CLI de OpenSpec upstream una vez revisado.
- La versión, el tag `v<versión>` y `npm publish` los hace el mantenedor.
